# Internationalization (i18n)

> **文档站 i18n 翻译维护已 PAUSED**：改 `docs/**/*.md` 时**不必**同步 `po/zh_CN/*.po`；`just check` / PR CI **不跑** `just i18n check` 等翻译校验。`po/` 与现有译文保留；`docs/.generated/zh_CN/` **不入库**，由 `just i18n po4a` 在 site 构建时从 PO 生成。产品 UI Paraglide **照常**。
>
> **壳层迁移后补跑**：英文 docs 已去掉 Electron/Capacitor 双轨叙述后，应 `just i18n po4a` 刷新 POT/PO，并清理已删除 master（如旧 `docs/sap/*`）对应的孤儿 `po/pot/*.pot` / `po/zh_CN/*.po`，避免 stale 中文产物。

FreeAnima uses **two complementary stacks**:

| Stack              | Content                                             | Consumers                                                                                                                                             |
| ------------------ | --------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Paraglide**      | Short UI strings (buttons, labels, errors)          | Site landing (`site/`), Habitat UI (`src/features/habitat/ui/habitat/`), shell UI (`src/frontend/app-ui/` + companion), `@freeanima/ui-kit/composite` |
| **po4a + gettext** | Long markdown docs + Paraglide message translations | Starlight docs (`docs/`), `messages/zh-cn.json`                                                                                                       |

**Code and scripts override this doc when they conflict.** Key counts and file paths may drift; verify with `bun scripts/check-paraglide-messages.ts` and `messages/en.json`.

## Principles

| Locale         | Source of truth                                     | Do not edit directly                                             |
| -------------- | --------------------------------------------------- | ---------------------------------------------------------------- |
| English (UI)   | [`messages/en.json`](../../messages/en.json)        | —                                                                |
| Chinese (UI)   | [`po/zh_CN/en.xml.po`](../../po/zh_CN/en.xml.po)    | [`messages/zh-cn.json`](../../messages/zh-cn.json) (po4a output) |
| English (docs) | [`docs/**/*.md`](../../docs/)                       | —                                                                |
| Chinese (docs) | [`po/zh_CN/*.po`](../../po/zh_CN/) (per doc master) | [`docs/.generated/zh_CN/`](../../docs/.generated/zh_CN/)         |

Additional rules:

- **Single catalog** for site landing (`landing_*`), Habitat (`console_*`), shared product UI (`ui_*`), and composite defaults — all read [`messages/paraglide/`](../../messages/paraglide/) compiled from the same JSON pair. Do not split into separate message files without an explicit RFC.
- **Terminology** for AI agents filling PO: [`i18n/glossary.md`](../../i18n/glossary.md); docs/PO authoring rules → [`docs-i18n.md`](docs-i18n.md).
- **Generated artifacts**: never hand-edit `messages/paraglide/`, `messages/.generated/`, or `docs/.generated/`.
- **No embedded translation tables** in TypeScript scripts; all UI strings go through `messages/en.json` + PO.

## Pipeline

### UI messages (Paraglide)

```
messages/en.json
  → gen-messages-po4a-master → messages/po4a/en.xml
  → po4a (+ po/zh_CN/en.xml.po) → messages/.generated/zh_CN.xml
  → compile-messages-from-po4a → messages/zh-cn.json
  → paraglide compile → messages/paraglide/ (site, CLI publish) and per-app outputs (Habitat, app-ui Vite builds)
  → site/ imports m.*() from messages/paraglide/
  → features/habitat/ui/habitat/ imports m.*() via @paraglide/messages alias
  → frontend/app-ui/ compiles to dist/.paraglide/ during Vite build
```

Entry command: `just i18n po4a` (runs the full chain above except Paraglide compile).

Paraglide compile:

- `just i18n paraglide` — writes shared [`messages/paraglide/`](../../messages/paraglide/) (product UI + Vite / standalone builds)
- **Site:** `site/package.json` `predev` / `prebuild` 直调 `bun scripts/i18n-po4a.ts` 与 `bun scripts/paraglide-compile.ts`（site 独立 `bun.lock`）
- **Habitat bundle:** [`src/features/habitat/build/paraglide-compile.ts`](../../src/features/habitat/build/paraglide-compile.ts) via [`scripts/build-cli.ts`](../../scripts/build-cli.ts)
- **Shell UI / satellites:** [`src/frontend/app-ui/vite/paraglide-plugin.ts`](../../src/frontend/app-ui/vite/paraglide-plugin.ts) compiles to each app's output dir (default `dist/.paraglide/`)

### Docs (markdown)

```
docs/**/*.md
  → po4a [type: text + markdown options] (+ po/zh_CN/<master>.po) → docs/.generated/zh_CN/**
```

Text module alias `docmd` applies `markdown`, `yfm_keys=title`, `yfm_lenient` (see [`po4a.cfg`](../../po4a.cfg)).

Same `just i18n po4a` run updates both UI and docs PO outputs. Site Starlight reads generated zh docs where configured.

**恢复翻译维护**：取消 PAUSED → agent 改 docs 时重新同步 PO → 可选恢复 `just i18n check` 入 PR 流程。

### Locale switching

| Surface      | Mechanism                                                                                          |
| ------------ | -------------------------------------------------------------------------------------------------- |
| Site landing | Route prefix (`/` vs `/zh-cn/`); `applySiteLocale()` in `site/src/lib/i18n.ts`                     |
| Habitat      | Runtime toggle; `localStorage` key `console-locale`; `src/features/habitat/ui/habitat/lib/i18n.ts` |

## Commands

| Command                                   | Purpose                                                                      |
| ----------------------------------------- | ---------------------------------------------------------------------------- |
| `just i18n po4a`                          | Full po4a pipeline: regen cfg, sync `en.xml`, run po4a, compile `zh-cn.json` |
| `just i18n messages-master`               | Regenerate `messages/po4a/en.xml` from `en.json` only                        |
| `just i18n messages-compile`              | Compile `zh-cn.json` from `messages/.generated/zh_CN.xml` (after po4a)       |
| `just i18n messages-bootstrap-po`         | One-time / repair: bootstrap `po/zh_CN/en.xml.po` from existing zh reference |
| `just i18n paraglide`                     | Compile `messages/paraglide/` from JSON pair                                 |
| `just i18n docs-check`                    | Source docs po4a-friendly structure (frontmatter, fences, tables)            |
| `just i18n docs-generated-check`          | Generated zh docs structure (fences, frontmatter)                            |
| `just i18n docs-english-check`            | Warn when doc PO msgstr still equals English msgid                           |
| `just i18n po-health`                     | PO health (warn on fuzzy / untranslated)                                     |
| `just i18n po-health-strict`              | Fail CI-style if fuzzy entries exist                                         |
| `bun scripts/check-paraglide-messages.ts` | Assert `en.json` and `zh-cn.json` keys match (manual; see `just i18n check`) |
| `just i18n check`                         | Run all i18n validation checks (not in CI / `just check`)                    |

## Developer workflow (new UI string)

1. Add `"key": "English text"` to [`messages/en.json`](../../messages/en.json). Use prefixes: `console_*` (Habitat), `landing_*` (site), `ui_*` (shared product UI / `@freeanima/ui-kit/composite` defaults).
2. Use the key in code: `m.key()` from Paraglide (`site/src/lib/i18n.ts`, `src/features/habitat/ui/habitat/lib/i18n.ts`, or app-ui/satellite Vite apps).
3. Run `just i18n po4a`. po4a updates `po/zh_CN/en.xml.po` with new `msgid` entries.
4. If `compile-messages-from-po4a` fails with **missing translation**: add `msgstr` in `po/zh_CN/en.xml.po` (same PR; see [`docs-i18n.md`](docs-i18n.md)), then rerun `just i18n po4a` or `just i18n messages-compile`.
5. Run `just i18n paraglide` (site / CLI) or rebuild the target app bundle (Habitat / app-ui Vite) so compiled messages pick up the new key.
6. Optional before PR / release: `just i18n check`.

Placeholders like `{detail}`, `{count}` must match between `msgid` and `msgstr`.

## AI i18n workflow (docs + PO) — PAUSED

文档 PO 同步已暂停。改 `docs/` 时只维护英文源文件。恢复后按下列步骤：

1. Read [`docs-i18n.md`](docs-i18n.md) and [`i18n/glossary.md`](../../i18n/glossary.md).
2. After editing [`docs/**/*.md`](../../docs/), fill empty/fuzzy `msgstr` in the matching [`po/zh_CN/<master>.po`](../../po/zh_CN/) (UI: [`en.xml.po`](../../po/zh_CN/en.xml.po)).
3. Run `just i18n po4a` → `just i18n po-health` → `just i18n docs-check` → `just i18n docs-generated-check`.
4. Optional before PR: `just i18n check` when UI keys or docs changed.

## CI and checks

- **Pre-commit** (`.husky/pre-commit`): does **not** run translation checks.
- **PR CI** / **`just check`**: i18n validation is **not** enforced (removed from `dep-check` to keep local/CI fast).
- **Site deploy** ([`.github/workflows/site.yml`](../../.github/workflows/site.yml)): site `prebuild` 跑 po4a + paraglide 生成中文文档（**不**跑 PO 严格校验）；`docs/.generated/zh_CN/` 不入库。
- **Manual / pre-release**: `just i18n check` (docs structure + PO strict + Paraglide keys + generated docs).

Interactive translation workflow: Cursor `/i18n-translate` (see [`.cursor/commands/i18n-translate.md`](../../.cursor/commands/i18n-translate.md)).

## Forbidden

- Maintaining duplicate English or Chinese strings in TypeScript merge scripts or inline catalogs.
- Hand-editing `messages/zh-cn.json`, `messages/paraglide/`, or `messages/.generated/`.
- Adding UI strings only to PO without a corresponding `messages/en.json` key (Paraglide requires the English catalog).
- Splitting site/Habitat message files without updating `project.inlang/settings.json` and the po4a pipeline.
