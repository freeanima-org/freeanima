# Internationalization (i18n)

> **文档站 i18n 翻译维护已 PAUSED**：改 `docs/**/*.md` 时**不必**同步 `po/zh_CN/*.po`；`just check` / PR CI **不跑** `just i18n check` 等翻译校验。`po/` 与现有译文保留；`docs/.generated/zh_CN/` **不入库**，由 `just i18n po4a` 在 site 构建时从 PO 生成。产品 UI Paraglide **照常**。
>
> **壳层迁移后补跑**：英文 docs 已去掉 Electron/Capacitor 双轨叙述后，应 `just i18n po4a` 刷新 POT/PO，并清理已删除 master（如旧 `docs/sap/*`）对应的孤儿 `po/pot/*.pot` / `po/zh_CN/*.po`，避免 stale 中文产物。

FreeAnima uses **three short-message catalogs** + docs po4a:

| Catalog  | Path                    | Consumers                                                                               |
| -------- | ----------------------- | --------------------------------------------------------------------------------------- |
| **site** | `messages/site/`        | 文档站落地（`landing_*`）；`project.site.inlang` → `messages/paraglide-site/`           |
| **ui**   | `messages/ui/`          | Portal + 全部 feature UI（含 habitat 管理台）；`project.inlang` → `messages/paraglide/` |
| **host** | `messages/host/`        | Habitat 进程提示词/错误；`@freeanima/host/core/i18n`（JSON runtime，非 Paraglide）      |
| **docs** | `docs/**` + `po/zh_CN/` | Starlight 长文（po4a）                                                                  |

根目录 `messages/en.json` / `zh-cn.json` 为 **ui catalog 镜像**（兼容旧脚本）。全局配置：`config.i18n.locale`（`en` \| `zh-cn`）、`config.i18n.timezone`（IANA）。

**Code and scripts override this doc when they conflict.** Verify UI keys with `bun scripts/check-paraglide-messages.ts`（针对 ui catalog）。

## Principles

| Locale         | Source of truth                                              | Do not edit directly                                     |
| -------------- | ------------------------------------------------------------ | -------------------------------------------------------- |
| English (UI)   | [`messages/ui/en.json`](../../messages/ui/en.json)           | —                                                        |
| Chinese (UI)   | [`po/zh_CN/en.xml.po`](../../po/zh_CN/en.xml.po)             | [`messages/ui/zh-cn.json`](../../messages/ui/zh-cn.json) |
| English (host) | [`messages/host/en.json`](../../messages/host/en.json)       | —                                                        |
| Chinese (host) | [`messages/host/zh-cn.json`](../../messages/host/zh-cn.json) | （可与 UI 共用 glossary；后续可接 PO）                   |
| English (site) | [`messages/site/en.json`](../../messages/site/en.json)       | —                                                        |
| English (docs) | [`docs/**/*.md`](../../docs/)                                | —                                                        |
| Chinese (docs) | [`po/zh_CN/*.po`](../../po/zh_CN/)                           | [`docs/.generated/zh_CN/`](../../docs/.generated/zh_CN/) |

Additional rules:

- **按 delivery consumer 三分 catalog**（site / ui / host）；Habitat 管理台文案归 **ui**，不单列。
- Host 禁止依赖 `messages/ui`；UI bundle 禁止打进 host catalog。
- **Terminology**：[`i18n/glossary.md`](../../i18n/glossary.md)；docs/PO → [`docs-i18n.md`](docs-i18n.md)。
- **Generated artifacts**: never hand-edit `messages/paraglide/`、`messages/paraglide-site/`、`messages/.generated/`、`docs/.generated/`。
- **No embedded translation tables** in TypeScript；UI 走 Paraglide，Host 走 `hostMsg()`。

## Pipeline

### UI messages (Paraglide)

```
messages/ui/en.json
  → (po4a 链可仍经根镜像 / en.xml.po)
  → paraglide compile (project.inlang) → messages/paraglide/
  → features/*/ui、client/app-frame、ui-kit 经 @paraglide/messages
```

### Site

```
messages/site/*.json → paraglide-compile-site.ts → messages/paraglide-site/
```

### Host

```
messages/host/*.json → hostMsg() / applyHostI18nConfig(config.i18n)
```

Entry command: `just i18n po4a` (runs the full chain above except Paraglide compile).

Paraglide compile:

- `just i18n paraglide` — writes shared [`messages/paraglide/`](../../messages/paraglide/) (product UI + Vite / standalone builds)
- **Site:** `site/package.json` `predev` / `prebuild` 直调 `bun scripts/i18n-po4a.ts` 与 `bun scripts/paraglide-compile.ts`（site 独立 `bun.lock`）
- **Habitat bundle:** [`src/features/habitat/build/paraglide-compile.ts`](../../src/features/habitat/build/paraglide-compile.ts) via [`scripts/build-cli.ts`](../../scripts/build-cli.ts)
- **Shell UI / satellites:** [`src/client/app-frame/vite/paraglide-plugin.ts`](../../src/client/app-frame/vite/paraglide-plugin.ts) compiles to each app's output dir (default `dist/.paraglide/`)

### Docs (markdown)

```
docs/**/*.md
  → po4a [type: text + markdown options] (+ po/zh_CN/<master>.po) → docs/.generated/zh_CN/**
```

Text module alias `docmd` applies `markdown`, `yfm_keys=title`, `yfm_lenient` (see [`po4a.cfg`](../../po4a.cfg)).

Same `just i18n po4a` run updates both UI and docs PO outputs. Site Starlight reads generated zh docs where configured.

**恢复翻译维护**：取消 PAUSED → agent 改 docs 时重新同步 PO → 可选恢复 `just i18n check` 入 PR 流程。

### Locale switching

| Surface      | Mechanism                                                                                          |
| ------------ | -------------------------------------------------------------------------------------------------- |
| Site landing | Route prefix (`/` vs `/zh-cn/`); `applySiteLocale()` in `site/src/lib/i18n.ts`                     |
| Habitat      | Runtime toggle; `localStorage` key `console-locale`; `src/features/habitat/ui/habitat/lib/i18n.ts` |

## Commands

| Command                                   | Purpose                                                                      |
| ----------------------------------------- | ---------------------------------------------------------------------------- |
| `just i18n po4a`                          | Full po4a pipeline: regen cfg, sync `en.xml`, run po4a, compile `zh-cn.json` |
| `just i18n messages-master`               | Regenerate `messages/po4a/en.xml` from `en.json` only                        |
| `just i18n messages-compile`              | Compile `zh-cn.json` from `messages/.generated/zh_CN.xml` (after po4a)       |
| `just i18n messages-bootstrap-po`         | One-time / repair: bootstrap `po/zh_CN/en.xml.po` from existing zh reference |
| `just i18n paraglide`                     | Compile `messages/paraglide/` from JSON pair                                 |
| `just i18n docs-check`                    | Source docs po4a-friendly structure (frontmatter, fences, tables)            |
| `just i18n docs-generated-check`          | Generated zh docs structure (fences, frontmatter)                            |
| `just i18n docs-english-check`            | Warn when doc PO msgstr still equals English msgid                           |
| `just i18n po-health`                     | PO health (warn on fuzzy / untranslated)                                     |
| `just i18n po-health-strict`              | Fail CI-style if fuzzy entries exist                                         |
| `bun scripts/check-paraglide-messages.ts` | Assert `en.json` and `zh-cn.json` keys match (manual; see `just i18n check`) |
| `just i18n check`                         | Run all i18n validation checks (not in CI / `just check`)                    |

## Developer workflow (new UI string)

1. Add `"key": "English text"` to [`messages/ui/en.json`](../../messages/ui/en.json)（并同步根镜像若脚本仍读根目录）。Site landing 用 `messages/site/`；Host 用 `messages/host/` + `hostMsg()`。
2. Use the key in code: `m.key()` from Paraglide，或 Host 侧 `hostMsg("key")`。
3. UI：Run `just i18n po4a` / `just i18n paraglide`。Site：`bun scripts/paraglide-compile-site.ts`。
4. Optional before PR: `just i18n check`.

## Forbidden

- Host 依赖 `messages/ui`，或 UI bundle 打进 host catalog。
- Hand-editing `messages/paraglide/`、`messages/paraglide-site/`、`messages/.generated/`。
- 为 Habitat 管理台单独开 catalog（归 ui）。
- 把 ui-kit / React 放入 `shared/`。
