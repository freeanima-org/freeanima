# 文案与文档语言

FreeAnima **无 i18n 运行时**（无 Paraglide / po4a / locale 切换）。

| 面              | 约定                                                               |
| --------------- | ------------------------------------------------------------------ |
| 产品 UI         | 源码内直接写**简体中文**                                           |
| Host 用户可见串 | 中文常量；`config.i18n.timezone` 仅保留 IANA 时区                  |
| `docs/**`       | **中文 SSOT**（Starlight 单站，无 locales）                        |
| 术语            | [`i18n/glossary.md`](../../i18n/glossary.md)（术语表，非翻译管线） |

## 禁止

- 再引入 Paraglide / inlang / gettext / po4a / 多 locale catalog
- Starlight `locales` / `/zh-cn` 内容路由 / 语言切换 UI
- 为「将来双语」预留未使用的 i18n 抽象
