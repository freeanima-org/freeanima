# Internationalization (i18n)

FreeAnima uses **two complementary stacks**:

| Stack              | Content                                             | Consumers                                                     |
| ------------------ | --------------------------------------------------- | ------------------------------------------------------------- |
| **Paraglide**      | Short UI strings (buttons, labels, errors)          | Site landing (`site/`), Admin UI (`platform/admin-frontend/`) |
| **po4a + gettext** | Long markdown docs + Paraglide message translations | Starlight docs (`docs/`), `messages/zh-cn.json`               |

**Code and scripts override this doc when they conflict.** Key counts and file paths may drift; verify with `bun scripts/check-paraglide-messages.ts` and `messages/en.json`.

## Principles

| Locale         | Source of truth                                     | Do not edit directly                                             |
| -------------- | --------------------------------------------------- | ---------------------------------------------------------------- |
| English (UI)   | [`messages/en.json`](../../messages/en.json)        | —                                                                |
| Chinese (UI)   | [`po/zh_CN/en.xml.po`](../../po/zh_CN/en.xml.po)    | [`messages/zh-cn.json`](../../messages/zh-cn.json) (po4a output) |
| English (docs) | [`docs/**/*.md`](../../docs/)                       | —                                                                |
| Chinese (docs) | [`po/zh_CN/*.po`](../../po/zh_CN/) (per doc master) | [`docs/.generated/zh_CN/`](../../docs/.generated/zh_CN/)         |

Additional rules:

- **Single catalog** for site landing (`landing_*`) and Admin (`admin_*`) — both read [`messages/paraglide/`](../../messages/paraglide/) compiled from the same JSON pair. Do not split into separate message files without an explicit RFC.
- **Terminology** for AI agents filling PO: [`i18n/glossary.md`](../../i18n/glossary.md); docs/PO authoring rules → [`docs-i18n.md`](docs-i18n.md).
- **Generated artifacts**: never hand-edit `messages/paraglide/`, `messages/.generated/`, or `docs/.generated/`.
- **No embedded translation tables** in TypeScript scripts; all UI strings go through `messages/en.json` + PO.

## Directory roles

| Path                                                                   | Role                                                                   |
| ---------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| [`messages/en.json`](../../messages/en.json)                           | Paraglide English catalog (inlang SSOT)                                |
| [`messages/zh-cn.json`](../../messages/zh-cn.json)                     | Paraglide Chinese catalog (compiled from PO)                           |
| [`messages/po4a/en.xml`](../../messages/po4a/en.xml)                   | po4a XML master (generated from `en.json`)                             |
| [`messages/.generated/zh_CN.xml`](../../messages/.generated/zh_CN.xml) | po4a UI translation output (intermediate)                              |
| [`messages/paraglide/`](../../messages/paraglide/)                     | Paraglide compile output (tree-shakeable `m.*()` functions)            |
| [`po/pot/`](../../po/pot/)                                             | gettext template files                                                 |
| [`po/zh_CN/`](../../po/zh_CN/)                                         | Chinese PO files (one per doc master + `en.xml.po` for UI)             |
| [`project.inlang/`](../../project.inlang/)                             | inlang project config; points plugins at `messages/{languageTag}.json` |
| [`po4a.cfg`](../../po4a.cfg)                                           | po4a paths (generated by `gen-po4a-cfg.ts`)                            |

## Pipeline

### UI messages (Paraglide)

```
messages/en.json
  → gen-messages-po4a-master → messages/po4a/en.xml
  → po4a (+ po/zh_CN/en.xml.po) → messages/.generated/zh_CN.xml
  → compile-messages-from-po4a → messages/zh-cn.json
  → paraglide compile → messages/paraglide/
  → site/ + platform/admin-frontend/ import m.*()
```

Entry command: `bun run i18n:po4a` (runs the full chain above except Paraglide compile).

Paraglide compile: `bun run paraglide:compile` (also invoked by `site` predev/prebuild and Admin bundle build via `site/package.json`).

### Docs (markdown)

```
docs/**/*.md
  → po4a [type: text + markdown options] (+ po/zh_CN/<master>.po) → docs/.generated/zh_CN/**
```

Text module alias `docmd` applies `markdown`, `yfm_keys=title`, `yfm_lenient` (see [`po4a.cfg`](../../po4a.cfg)).

Same `i18n:po4a` run updates both UI and docs PO outputs. Site Starlight reads generated zh docs where configured.

### Locale switching

| Surface      | Mechanism                                                                                        |
| ------------ | ------------------------------------------------------------------------------------------------ |
| Site landing | Route prefix (`/` vs `/zh-cn/`); `applySiteLocale()` in `site/src/lib/i18n.ts`                   |
| Admin        | Runtime toggle; `localStorage` key `admin-locale`; `platform/admin-frontend/app/src/lib/i18n.ts` |

## Commands

| Command                                   | Purpose                                                                      |
| ----------------------------------------- | ---------------------------------------------------------------------------- |
| `bun run i18n:po4a`                       | Full po4a pipeline: regen cfg, sync `en.xml`, run po4a, compile `zh-cn.json` |
| `bun run i18n:messages:master`            | Regenerate `messages/po4a/en.xml` from `en.json` only                        |
| `bun run i18n:messages:compile`           | Compile `zh-cn.json` from `messages/.generated/zh_CN.xml` (after po4a)       |
| `bun run i18n:messages:bootstrap-po`      | One-time / repair: bootstrap `po/zh_CN/en.xml.po` from existing zh reference |
| `bun run paraglide:compile`               | Compile `messages/paraglide/` from JSON pair                                 |
| `bun run docs:i18n:check`                 | Source docs po4a-friendly structure (frontmatter, fences, tables)            |
| `bun run i18n:docs:generated:check`       | Generated zh docs structure (fences, frontmatter)                            |
| `bun run i18n:docs:english:check`         | Warn when doc PO msgstr still equals English msgid                           |
| `bun run i18n:docs:check`                 | PO health (warn on fuzzy / untranslated)                                     |
| `bun run i18n:docs:check:strict`          | Fail CI-style if fuzzy entries exist                                         |
| `bun scripts/check-paraglide-messages.ts` | Assert `en.json` and `zh-cn.json` keys match                                 |

## Developer workflow (new UI string)

1. Add `"key": "English text"` to [`messages/en.json`](../../messages/en.json). Use prefixes: `admin_*` (Admin), `landing_*` (site).
2. Use the key in code: `m.key()` from Paraglide (`site/src/lib/i18n.ts` or `platform/admin-frontend/app/src/lib/i18n.ts`).
3. Run `bun run i18n:po4a`. po4a updates `po/zh_CN/en.xml.po` with new `msgid` entries.
4. If `compile-messages-from-po4a` fails with **missing translation**: add `msgstr` in `po/zh_CN/en.xml.po` (same PR; see [`docs-i18n.md`](docs-i18n.md)), then rerun `bun run i18n:po4a` or `bun run i18n:messages:compile`.
5. Run `bun run paraglide:compile` (or `site` prebuild / Admin bundle) so `messages/paraglide/` picks up the new key.
6. Before PR: `bun scripts/check-paraglide-messages.ts`.

Placeholders like `{detail}`, `{count}` must match between `msgid` and `msgstr`.

## AI i18n workflow (docs + PO)

No human translators — agents maintain English docs and Chinese PO in the same PR.

1. Read [`docs-i18n.md`](docs-i18n.md) and [`i18n/glossary.md`](../../i18n/glossary.md).
2. After editing [`docs/**/*.md`](../../docs/), fill empty/fuzzy `msgstr` in the matching [`po/zh_CN/<master>.po`](../../po/zh_CN/) (UI: [`en.xml.po`](../../po/zh_CN/en.xml.po)).
3. Run `bun run i18n:po4a` → `bun run i18n:docs:check` → `bun run docs:i18n:check` → `bun run i18n:docs:generated:check`.
4. Before PR: `bun scripts/check-paraglide-messages.ts` when UI keys changed.

## CI and checks

- [`.github/workflows/site.yml`](../../.github/workflows/site.yml): runs `i18n:po4a` and `check-paraglide-messages.ts` before site build.
- Fuzzy PO entries are allowed by default (`i18n:docs:check` warns); use `--strict` to fail.

## Forbidden

- Maintaining duplicate English or Chinese strings in TypeScript merge scripts or inline catalogs.
- Hand-editing `messages/zh-cn.json`, `messages/paraglide/`, or `messages/.generated/`.
- Adding UI strings only to PO without a corresponding `messages/en.json` key (Paraglide requires the English catalog).
- Splitting site/Admin message files without updating `project.inlang/settings.json` and the po4a pipeline.
